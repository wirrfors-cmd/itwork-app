# 🎯 Пошаговая инструкция: от кода к iPhone

## ✅ Шаг 1: Подготовьте локально (5 минут)

На вашем компьютере (Windows/Linux/Mac):

```bash
# Откройте терминал в папке проекта
cd itwork-app

# Установите зависимости
npm install

# Проверьте, что всё работает (разработка)
npm run dev
```

Откройте http://localhost:5173 — должно работать ваше приложение.

**Готово!** Остановите dev-сервер (Ctrl+C).

---

## 📤 Шаг 2: Залейте на GitHub (10 минут)

### 2.1. Создайте пустой репозиторий на GitHub

1. Перейдите на https://github.com/new
2. Введите имя: `itwork-app`
3. Выберите **Private** (если не хотите делиться кодом)
4. Нажмите **Create repository**
5. **НЕ создавайте README** на GitHub!

### 2.2. Загрузите ваш код

На терминале в папке проекта:

```bash
git init
git add .
git commit -m "Initial commit: Capacitor setup"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/itwork-app.git
git push -u origin main
```

**Готово!** Ваш код на GitHub.

---

## 🔨 Шаг 3: Включите автоматическую сборку (10 минут)

### 3.1. Зарегистрируйтесь на Ionic.io

1. Откройте https://ionic.io/
2. Нажмите **Start free** (вверху справа)
3. Заполните форму (Email, пароль)
4. **Очень важно**: выберите **Ionic AppFlow** на шаге выбора плана
5. Подтвердите email

### 3.2. Подключите GitHub репозиторий

1. На главной странице AppFlow нажмите **+ New App** (вверху справа)
2. Выберите **Connect Existing Repository**
3. Нажмите **GitHub**
4. Дайте разрешение Ionic доступ к GitHub:
   - Нажмите **Authorize ionic-io**
   - Выберите ваш аккаунт GitHub
   - Дайте разрешения
5. Выберите репозиторий `itwork-app`
6. Нажмите **Connect**

**Готово!** AppFlow подключен.

---

## 🍎 Шаг 4: Первая сборка iOS (15 минут)

### 4.1. Запустите сборку

1. На странице вашего приложения в AppFlow нажмите **Build** (слева)
2. Нажмите **New Build** (справа)
3. Выберите **iOS**
4. **Target:** Production (по умолчанию)
5. **Build Stack:** выберите свежую версию (например, "Xcode 15")
6. Нажмите **Start Build**

Сборка займёт **3-5 минут**. Следите за логом.

### 4.2. Скачайте приложение

Когда сборка закончится (статус "Build Completed"):

1. Нажмите на неё
2. Нажмите **Download IPA**
3. Сохраните файл `itwork-app.ipa`

**Готово!** У вас есть iOS-приложение.

---

## 📲 Шаг 5: Установите на iPhone (выбирайте вариант)

### Вариант A: Через Finder (самый простой)

**Требуется:** Mac + USB кабель

```
1. Подключите iPhone к Mac
2. Откройте Finder → Устройства → ваш iPhone
3. Откройте вкладку "Программы"
4. Перетащите itwork-app.ipa в список программ
5. Дождитесь установки
```

### Вариант B: Через TestFlight (бесплатно, без Mac)

**Требуется:** Apple ID

```
1. На Ionic AppFlow на странице сборки нажмите "Share"
2. Выберите "TestFlight"
3. Введите email Apple ID
4. На iPhone откройте email → перейдите по ссылке
5. Установите приложение из TestFlight
```

### Вариант C: Через Xcode (требует Mac)

```
1. Скачайте Xcode на Mac
2. Откройте Xcode
3. Window → Devices and Simulators
4. Выберите iPhone
5. Нажмите "+" → выберите itwork-app.ipa
```

## 🔄 Шаг 6: Автоматические обновления (навсегда)

Теперь каждый раз, когда вы делаете изменения:

```bash
# На вашем компьютере:
# 1. Отредактируйте приложение
# 2. Сохраните изменения
# 3. Закоммитьте и запушьте:

git add .
git commit -m "Добавил новую функцию"
git push
```

**Автоматически**:
- AppFlow скачивает новый код
- Собирает новую версию
- Вы скачиваете обновленный .ipa
- Устанавливаете на iPhone

## 🆘 Проблемы?

| Проблема | Решение |
|----------|---------|
| Сборка падает | Проверьте логи в AppFlow. Нажмите на сборку → посмотрите Build Logs |
| GitHub не видит код | Убедитесь, что выполнили `git push` |
| Приложение не устанавливается | Проверьте версию iOS на iPhone (должна быть iOS 13+) |
| Не видно TestFlight | Проверьте, что ввели правильный Apple ID email |
